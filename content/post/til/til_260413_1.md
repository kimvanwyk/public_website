My employer runs a [pypiserver](https://pypi.org/project/pypiserver/) instance as a simple repository of internal Python modules. It inevitably happened recently that I published a package to it that was broken and should not be used. I had to remind myself how to remove a package from the server and found [this guide](https://stackoverflow.com/questions/24309586/remove-packages-from-local-pypi-index).

The supplied action in the POST payload is ":action" and the colon gave [httpie](https://httpie.io/) some trouble. As a self-reminder, this is what worked:
```bash
https -f SERVER_URL "\:action"=remove_pkg name=PACKAGE_NAME version="1.0.0"
```
